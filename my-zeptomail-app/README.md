# ZeptoMail Dispatcher for Cloudflare Pages

A lightweight, dark-themed mailer UI built with Tailwind CSS and powered by Cloudflare Pages Functions and Zoho ZeptoMail API.

## Cloudflare Pages Setup

1. Connect this repository to **Cloudflare Pages**.
2. **Build settings**:
   - **Build command:** *(leave empty)*
   - **Build output directory:** `public`
3. **Environment Variables**:
   - `ZEPTOMAIL_API_TOKEN`: Your ZeptoMail Send Mail API token (`Zoho-enczapikey ...`)
